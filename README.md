# Diwash Acharya — Static Portfolio

A vanilla HTML/CSS/JavaScript portfolio inspired by the Abdul Rehman Waseem portfolio site.

## Included

- Dark, grid-based, minimal developer aesthetic
- Sticky top navigation: Portfolio / Blog / Products
- DA brand mark and large hero
- Nepal flag + profile header
- Verified-style badge and pronounce button
- Overview/contact information
- GitHub / LinkedIn / Instagram / Contact cards
- About section
- Contribution-style activity heatmap
- Large technology stack grid
- Expandable project list
- Achievements & highlights
- Blog cards
- Products cards
- Dark/light theme toggle
- Command palette (`Ctrl+K` / `⌘K`)
- Back-to-top button
- Responsive mobile layout
- No backend, no database, no build step required

## Run

Just open `index.html` in a browser.

For the best local development experience, use VS Code Live Server or any static HTTP server. No Node.js installation is required.
y icons use the Devicon CDN. The site itself has no backend.
